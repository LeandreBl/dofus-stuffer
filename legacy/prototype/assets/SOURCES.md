# Sources des icônes

`game-stat-icons.png` est une planche d’icônes du jeu DOFUS distribuée dans le dépôt public Souchy/DofusDB. Copie locale du 7 octobre 2026 pour que le prototype fonctionne hors ligne.

- Image : https://cdn.jsdelivr.net/gh/Souchy/DofusDB@master/scraped/common/icons.png
- Référence des coordonnées : https://github.com/Souchy/DofusDB/blob/master/db.ts

Les visuels DOFUS restent la propriété de leurs ayants droit, dont Ankama. La licence du code du projet ne constitue pas une licence accordée sur ces visuels tiers.

Le prototype utilise l’icône générique de dommages pour Flèche punitive et la lettre K pour le budget. Les icônes exactes des sorts et des kamas devront être associées aux données du jeu lors de l’intégration du catalogue versionné.
